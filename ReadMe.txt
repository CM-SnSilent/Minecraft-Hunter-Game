介绍：
猎人游戏分为猎人、猎物两个队伍。
猎人：身上有指向猎物的指南针，杀死猎物即可获胜；
猎物：有多个猎物时死亡会变成旁观者。仅一条命，末影龙死亡即可获胜。

加载：
客户端服务端都不要装Forge，数据包不用解压，不然无法加载。
将数据包放入你存档的【datapacks】文件夹后进入存档，路径：.minecraft\saves\你的存档\datapacks\。

警告：
游玩请新建一个存档使用，不要在同个存档游玩第二次；
指南针通过 /item 放入物品栏第九格，此格无法放置其他东西。

功能：
将鼠标放在选项上会有提示框告诉你有什么作用：
【初始化包】所有玩家进来后点一下，重置所有选项；
【猎人效果】开局给予猎人失明跟缓慢，默认关闭；
【击杀发光】猎物每次击杀猎人都会发光，默认关闭；
【成为猎物】选择自己成为猎物，默认随机分配一个；
【旁观者席】游戏开始后变成旁观者模式，默认关闭；
【友军伤害】队友是否可以互相伤害，默认关闭；
【猎人复活】猎人是否能无限复活，默认开启；
【对半分配】随机分配一半人数为猎物，默认关闭；
【死亡掉落】死亡是否掉落身上的物品，默认开启；
【简单模式】猎物拥有初始物品，猎人永久发光，默认关闭；
【交换模式】猎物每隔两分钟会互相交换操作一个角色，默认关闭；
【开始游戏】嗯···就是开始游戏。
